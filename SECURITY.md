# Security

NOID holds people's money, so security reports are very welcome.

**Report privately.** Please don't open a public issue for a security
problem. Use GitHub's private reporting instead: the **Security** tab of this
repository, then **Report a vulnerability**. You can also message David on
Telegram ([@dpeluola](https://t.me/dpeluola)).

Please include what you found, how to reproduce it, and which version
(Settings shows it). We'll reply as soon as we can and credit you in the fix
unless you'd rather stay anonymous.

**In scope:** the app (`app/`), the wallet core (`core/`), the wallet server
(`backend/`) and the pages on noidusa.com (`site/`).

**Good places to start:** [REVIEW.md](REVIEW.md) explains how keys are kept,
how a payment is built and proven on the phone, and what the app does to
stay safe when the wallet server is dishonest.
